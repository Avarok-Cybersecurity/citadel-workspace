## The record and the guards

Read these two before investigating anything, and before writing a new check.

- [GATES.md](GATES.md) — every mechanical guard, what it asserts, and why.
  **Read it before writing a guard.** Four guards in one campaign were written
  that already existed elsewhere, and better, because nothing listed what was
  already here. Generated by `scripts/build-gates-index.mjs`.
- [ROBUSTNESS.md](ROBUSTNESS.md) — the parent repo's findings record, **rounds
  477–730**. Note that `citadel-workspaces/docs/ROBUSTNESS.md` is a SECOND file
  of the same name covering **rounds 136–550**; the ranges overlap, so a round
  number alone does not identify a finding. Grepping only one of them reads part
  of the record and misses the rest.
- [AGENT_README.md](AGENT_README.md) — the shipped agent's own README.
